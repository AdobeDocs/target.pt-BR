# Introdução a experiências e ofertas {#experiences-overview}

>[!BEGINSHADEBOX]

**Nesta página:** saiba o que é uma experiência no [!DNL Adobe Target] e quais compositores de experiência estão disponíveis para criar experiências.

>[!ENDSHADEBOX]

Uma experiência no [!DNL Adobe Target] determina qual conteúdo aparece quando um visitante atende aos critérios de público-alvo de uma atividade.

Uma experiência pode ser uma oferta, imagem, texto, botão, vídeo, uma combinação desses elementos em uma página, uma página da Web inteira ou um conjunto de páginas que talvez forme um funnel de compra ou outra sequência lógica de páginas. Também pode ser a resposta de um assistente de voz, um script de atendimento ao cliente ou até mesmo um sabor personalizado de uma máquina bebidas. As experiências são testadas ou personalizadas em [!DNL Target] atividades.

Uma atividade normalmente contém mais de uma experiência. Por exemplo, os visitantes da área de Salt Lake City podem visualizar uma oferta de desconto de US$ 30 em botas para esqui, enquanto os visitantes de San Diego visualizam um desconto para roupas de banho. Uma página com diferentes ofertas especiais para visitantes recorrentes também pode ser testada. Cada uma dessas ofertas está apresentada em uma experiência separada.

[!DNL Target] fornece os seguintes compositores de experiência:

| Tipo | Detalhes |
| --- | --- |
| [Visual Experience Composer (VEC)](/help/main/c-experiences/c-visual-experience-composer/visual-experience-composer.md) | O VEC é um dos principais recursos do [!DNL Adobe Target]. É um editor que permite aos profissionais de marketing e designers criarem e alterarem o conteúdo usando uma interface visual. Muitas opções de design podem ser feitas sem a edição direta do código. O HTML e o JavaScript também podem ser editados, usando as opções de edição disponíveis no compositor. |
| [Experience Composer baseado em formulário](/help/main/c-experiences/form-experience-composer.md) | O Experience Composer baseado em formulário oferece a criação de experiências não visuais. Ele permite que testes A/B do [!DNL Target Standard], direcionamento de experiência, Automated Personalization e atividades do [!DNL Recommendations] sejam entregues em emails, quiosques e outros locais que não funcionam com o Visual Experience Composer. |
| [Aplicativo de página única (SPA) no Visual Experience Composer (VEC)](/help/main/c-experiences/spa-visual-experience-composer.md) | O VEC for SPAs permite que os profissionais de marketing criem testes e personalizem conteúdo em SPAs de maneira independente, sem dependências de desenvolvimento contínuas. Ela pode ser usada para criar atividades de Teste A/B e Direcionamento de experiência (XT) em estruturas populares, como o React e o Angular. |
